Kondisi Sebelumnya (Pain Points)

Silo data & proses manual yang membebani tim

Silo data antar departemen menyebabkan inefisiensi dan risiko aset hilang tanpa jejak:

  • Inventaris Tidak Sinkron: Spreadsheet terpisah di tiap divisi menyebabkan status kepemilikan laptop dan monitor tidak tercatat akurat saat mutasi.
  • Tiket Hilang Tanpa SLA: Permintaan perbaikan via pesan instan pribadi sering terlewat tanpa metrik durasi resolusi yang jelas.
  • Beban Tiket Berulang: Pertanyaan standar (konfigurasi WiFi, VPN, printer) terus ditanyakan karena belum adanya portal panduan mandiri.

Solusi: TrackIT Platform

Single Source of Truth

Satu platform terpadu yang menghubungkan seluruh siklus perangkat dan manajemen layanan:

  • End-to-End Asset Lifecycle: Mulai dari pengadaan, penomoran seri, serah terima NIK, perbaikan, hingga disposal terstandarisasi.
  • Realtime Ticketing Engine: Insiden terhubung otomatis ke ID aset pelapor, terupdate live via Server-Sent Events (SSE).
  • Self-Service Knowledge Hub: Dokumentasi interaktif berbasis WYSIWYG editor dengan pencarian instan untuk karyawan.

Arsitektur Sistem & Fondasi Engineering

Dibangun untuk performa tinggi, modularitas bersih, dan standar keamanan enterprise.

Slide 03

Frontend SPA

Vue 3 Composition API + Vite 8 dengan token CSS modular dan lightweight chunks.

  • Dynamic Code-Splitting (~77 KB Chunks)
  • SheetJS 0.20.3 (Zero-CVE Excel Parser)
  • TipTap Editor + DOMPurify Sanitizer
  • Kepatuhan Aksesibilitas WCAG 2.1 AA

Backend & SSE Engine

Node.js Express + Server-Sent Events (SSE) untuk push updates instan tanpa overhead websocket.

  • Realtime SSE stream (tanpa polling boros)
  • Decoupled IP & Akun Rate Limiting
  • PostgreSQL Relational DB dengan Transaksi
  • Multi-Layer Origin & CSRF Guard

Security & Testing

Jaminan mutu melalui rangkaian pengujian otomatis menyeluruh dan perlindungan zero-trust.

  • 217/217 Tests Passing (100%)
  • HttpOnly + SameSite=Lax Cookie Auth
  • Strict Headers: CSP, XFO, CORP, CT
  • Audit Log terenkripsi permanen

06 / 20 • Demo Tahap 2: Zero-Trust Auth

Autentikasi Aman & Proteksi Sesi

Sesi terproteksi HttpOnly, anti brute-force, dan pemisahan limit IP/akun.

Slide 06

Fondasi Keamanan Login

Arsitektur otentikasi tanpa token di localStorage, kebal serangan XSS token theft:

  • HttpOnly Session Cookie: Token tersimpan di cookie browser yang tidak dapat dibaca oleh skrip JavaScript manapun.
  • Decoupled Rate Limiter: Memisahkan kuota limit IP (60/15m) dan akun (10/15m) sehingga tidak mengunci satu kantor (Anti-NAT DoS).
  • Auto-Clear on Success: Saat pengguna berhasil login, counter kegagalan langsung di-reset otomatis ke nol.
Langkah Demo Presenter:
1. Buka /login
2. Masukkan kredensial demo dari environment variabel (jangan tampilkan nilai literal).
3. Klik "Masuk" → Masuk langsung ke Dashboard Utama
