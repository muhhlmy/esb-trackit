  • Pilih pemberi, penerima, dan pihak mengetahui
  • Autofill dari master karyawan
  • Pilih aset baru/lama dari inventory
  • Tujuan: baru, pinjam, perbaikan, disposal, lainnya
  • Generate formulir siap cetak / PDF

  • Search, filter status, dan filter tanggal
  • Status: Belum Dikirim → Pending → Sedang Dikirim → Diterima / Cancel
